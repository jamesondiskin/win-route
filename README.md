As someone who likes the idea of a "living room PC" but hates the idea of using two different PCs with mismatched specs (and thus getting different gaming or productivity performance) the main problem I had was switching the audio devices from my desktop setup with a multichannel mixer to the TV, which only has one audio output. This simple C based program streamlines the process and when used in tandem with software like DisplayFusion it works flawlessly. 

Upon first initialization, it creates an .ini file that acts as a configuration file where you can change settings, device inputs, delays, and more.
